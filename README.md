# Borgo delle Creature

Idle 2D cozy moderno-magico. Nuovo progetto indipendente da Creature-Sanctuary.

## Per Codex

Leggere `AGENTS.md`, poi eseguire interamente `CODEX_TASK.md`. Specifiche in `docs/`; dati iniziali in `design/balance.v1.json`.

Obiettivo: una prima versione giocabile completa del quartiere iniziale, con progresso automatico, interazione tattile utile, crescita, sblocchi e salvataggio offline. Non fermarsi alla pianificazione o allo scaffold.

Riferimento artistico: `docs/art/concept-reference.jpg` (concept illustrato; interfaccia e personaggi provvisori). Fondale ed edifici statici, creature separate con microanimazioni.

Stato iniziale: documentazione di progetto, nessuna implementazione ancora consegnata.
